# Agriculture Management System
A web-based Agriculture Management System developed using PHP, MySQL, HTML, CSS and Bootstrap.
## Features
- User Registration and Login
- Farmer and Buyer Management
- Product Management
- Digital Agriculture Market
- Shopping Cart
- Order Management
- Farmer Order Status Management
